Split the superadmin System Configuration page (`/superadmin/config`) into three nested-route tabs mirroring the org-config pattern: System Configuration (non-secret defaults, enrichment gate, and enrichment toggles saved via PATCH /admin/system/config), Registration (mode loaded from GET /admin/system/registration with 404 fallback to GET /v1/auth/registration-status, saved via PATCH /admin/system/registration), and Runtime (read-only masked secrets from GET /admin/system/settings with per-key reveal). Tab switches route through the shared `useConfigDirty().navigate` unsaved-changes guard and each editable tab owns a `StickySaveBar`.
